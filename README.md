# Бот для TikTok и Instagram

Python-бот на **pyTelegramBotAPI**. **yt-dlp** получает видео и доступные форматы, **FFmpeg** объединяет дорожки и извлекает MP3. Дополнение `curl-cffi` позволяет yt-dlp использовать поддерживаемый им режим браузерных запросов к Instagram.

## Возможности

- Приветствие `/start`, подсказка `/help` и понятные сообщения об ошибках.
- Публичные видео TikTok (включая короткие ссылки) и Instagram Reels/видеопубликации.
- После ссылки — кнопки доступных разрешений и «Только звук · MP3» (128 кбит/с).
- Разрешения берутся из ответа сайта. Если доступен только один формат, кнопка будет одна. Повышение разрешения не выполняется.
- Максимальный размер отправки — 49 МиБ; если файл больше, бот предложит меньшее качество.
- Два одновременных задания, не больше одного на пользователя; временные файлы удаляются и при ошибке.
- Меню привязано к пользователю и чату, действует 15 минут, используется один раз. После перезапуска нужна новая ссылка.

Фото, альбомы, подборки, прямые эфиры и YouTube не поддерживаются. Instagram и TikTok могут ограничивать скачивание по региону, IP, авторизации или изменениям сайта. Наличие кнопки не гарантирует, что удалённый сервис разрешит последующую загрузку. Сохраняйте материалы, на которые у вас есть права.

## Установка

Рекомендуется **Python 3.12**: установка и тесты проверены на этой версии. Также нужен **FFmpeg** с `ffprobe` в `PATH`. Предварительные версии Python, включая 3.15, не проверены: для них могут отсутствовать готовые пакеты зависимостей.

Ubuntu/Debian:

```bash
sudo apt-get update
sudo apt-get install -y python3-venv ffmpeg
```

macOS: `brew install python ffmpeg`. Windows: установите Python и FFmpeg, добавьте их в `PATH`.

В каталоге репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

### Windows (PowerShell)

Установите Python 3.12 с python.org (с Python Launcher) или командой:

```powershell
winget install --exact --id Python.Python.3.12
```

Откройте новое окно PowerShell в каталоге проекта:

```powershell
py -3.12 -m venv .venv312
.\.venv312\Scripts\python.exe -m pip install --upgrade pip
.\.venv312\Scripts\python.exe -m pip install -r requirements.txt
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
```

После сохранения токена запустите:

```powershell
.\.venv312\Scripts\python.exe youtube_down.py
```

Активация окружения не требуется. Отдельное имя `.venv312` позволяет сохранить старое окружение и существующий `.env`. Если `py -3.12` не найден, проверьте установку Python 3.12 и Launcher.

Ошибка `Building wheel for brotli` / `Microsoft Visual C++ 14.0 or greater is required` означает, что pip пытается собрать зависимость из исходников. Если в выводе есть `cpython-315`, используется Python 3.15. Выполните команды выше с Python 3.12; устанавливать компилятор для обычного запуска бота не требуется.

Получите **новый** токен у [@BotFather](https://t.me/BotFather), впишите его в `.env`:

```dotenv
TELEGRAM_BOT_TOKEN=ваш_токен
```

Файл `.env` исключён из Git. Старый токен из прежней версии репозитория удалён из текущего кода, но остаётся в истории Git: отзовите его у BotFather. Не отправляйте токены и cookies в чат или коммиты.

## Запуск

```bash
python youtube_down.py
```

Альтернативно: `python -m downloader_bot.app`. Запускайте один экземпляр polling на токен. При запуске бот автоматически отключает прежний webhook, поскольку Telegram не разрешает одновременно использовать webhook и polling. Если этот токен используется другим сервисом с webhook, сначала остановите тот сервис или создайте отдельного бота. Остановка — `Ctrl+C`. Старые обновления при запуске пропускаются; активные задания завершаются при штатной остановке.

Откройте бота в Telegram, нажмите `/start`, отправьте ссылку и выберите кнопку. MP4 отправляется как видео, MP3 — как аудио, другой исходный контейнер — как документ. Файл в исходном контейнере не всегда подходит для встроенного проигрывателя Telegram.

Если не хватает прав на просмотр публикации, можно указать `YTDLP_COOKIE_FILE` — абсолютный путь к файлу cookies в Netscape-формате. Используйте только свою учётную запись и храните файл вне репозитория с ограниченными правами. Cookies не гарантируют доступ и боту для публичных публикаций обычно не нужны.

Для облака необходим доступ к `api.telegram.org`, доменам TikTok/Instagram и их CDN. Точные CDN зависят от видео; ошибки сетевой политики нужно устранять в настройках окружения. Не отключайте проверку TLS. Токен также можно задать через секрет `TELEGRAM_BOT_TOKEN` в настройках облачного окружения; подключение к Telegram проверяется при запуске.

## Проверка

```bash
python -m pip install -r requirements-dev.txt
python -m pip check
python -m pytest -q
```

Тесты проверяют ссылки, динамическое меню, защиту callback-кнопок, обработку ошибок, лимиты и очистку файлов. Интеграционные тесты создают настоящее MP4 через FFmpeg, скачивают его через локальный HTTP-сервер с yt-dlp и извлекают MP3. Telegram в тестах заменён имитацией: реальные токен и публикации не требуются. Это не заменяет ручную проверку доступности TikTok/Instagram и отправки файлов через Telegram.

Для ручной проверки: отправьте одну доступную ссылку TikTok и одну Instagram; попробуйте каждое качество и звук, неправильную ссылку и повторное нажатие кнопки. Проверьте получение и воспроизведение файлов. В этом окружении живые Telegram/социальные запросы не проверены без нового токена и доступных примеров.

Сайты меняются. Для обновления загрузчика используйте `python -m pip install --upgrade 'yt-dlp[default,curl-cffi]'`, затем повторите тесты и ручную проверку. Для воспроизводимой установки обновите закреплённую версию в `requirements.txt` после проверки.

## Структура

- `downloader_bot/app.py` — сообщения, кнопки, отправка файлов.
- `downloader_bot/media.py` — проверка ссылок, форматы, загрузка.
- `downloader_bot/state.py` — временные меню и пул заданий.
- `downloader_bot/config.py` — чтение настроек.
- `tests/` — автоматические проверки.
